# Invoker mod (Fabric 1.21.11)

- Клавиши: Z = огонь, X = вода, C = воздух (работают, только если в инвентаре есть книга).
- Книга инвокера (кд 2 с): книга + огненный порошок + лазурит + перо.
- Супер-книга (кд 0.5 с): книга инвокера в центре, 7 алмазов вокруг, сверху шаблон незеритового улучшения.
